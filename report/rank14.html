왜 떡상했나 — 편집 장치를 시간대별로

  1. 0–3초아픈 꾸이

    얼음주머니·휴지 더미 = 아픔을 한눈에.

  2. 3–14.5초교차 통화

    집 ↔ 거리 교차 컷 + '뭐라고?!!!!' 남친 클로즈업 = 통화 드라마.

  3. 14.5–25초헌신 몽타주

    약국 '텐텐도 주세요!' · 비빔밥 포장 = 남친의 헌신.

  4. 25–31.8초반전 엔딩

    떡볶이 먹으며 '다 나았당~!' → 남친 허탈 = 커플 공감 개그 → 태그 유도.
