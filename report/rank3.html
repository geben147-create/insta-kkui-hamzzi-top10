카메라는 모든 샷에서 고정(락오프) — 움직임은 캐릭터만. 마지막 샷만 20.97초에 4프레임 크래시 줌(펀치 인) 후 천천히 푸시인해 눈물 익스트림 클로즈업으로 끝남(자동 감지가 놓쳐 프레임 확인으로 13샷으로 보정).

왜 떡상했나 — 편집 장치를 시간대별로

  1. 0.0–1.5초유명 브랜드 유니폼 + 노래

    작은 캐릭터가 누구나 아는 패스트푸드 유니폼을 입고 흥얼거리며 버거를 만듦 → 설정이 1초 만에 이해됨.

  2. 6.0–11.6초점점 빨라지는 몽타주

    샷 길이 6.0 → 1.07 → 1.03 → 0.67 → 0.40 → 0.83초. 리듬이 빨라지며 '일 잘하는 중' 에너지 상승.

  3. 7.1–9.2초음식 광고 인서트

    튀김 기름·감튀 쏟아지는 클로즈업(0.4초 초단 컷 포함) = 만족감 ASMR.

  4. 8.1–10.0초스케일 개그 ①

    캐릭터가 담는 감튀 상자가 손톱만 함 — 뒤에 나올 반전의 복선.

  5. 11.6–16.3초반전: 거대 손님

    근육질 보디빌더 vs 작은 봉투. '뭐야 이게…?' → '간에 기별도 안 가겠네…' = 한국어 관용구 공감 개그.

  6. 16.3–19.7초3초 정적

    손님이 나가는 뒷모습 + 남겨진 봉투. 자막 없는 침묵이 슬픔을 만듦.

  7. 19.7–22.4초이중 펀치라인

    '열심히 만들었는데…'(슬픔) → 크래시 줌 → '그 와중에 맛있어…'(자기 위로 개그). 댓글 유발.

  8. 전체3개 언어 자막 + 꾸이 노래

    캐릭터는 '꾸이' 노래만, 뜻은 한·영·일 자막. 사람 배우만 한국어 대사.
